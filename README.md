## 一、先分清你的服属于哪一类

同样是 MC 服务端，纯净原版、插件服、模组服对内存的要求能差两三倍。先按这个分档，再去看 CPU 和机型，顺序反了容易买贵或者买废。

**原版或 Paper 纯净服，2~5 人。** 2 核 2G 可用，启动时给 Java 分 1.2~1.5GB，剩下的留给系统和面板。Paper 比原版省内存，同样配置下 TPS 也更稳。

**Paper 加常用插件。** Essentials、LuckPerms 这类轻插件问题不大，Dynmap 这种实时网页地图会额外吃资源，2G 内存下要把刷新频率调低，或者干脆不开。

**Forge / Fabric 模组服。** 2G 基本不够，轻量整合包也会因为内存不足频繁卡顿甚至崩服，4GB 以上才谈得上稳定。整合包越大，内存和单核压力一起涨。

**高版本（1.21 这类）加模组或插件。** 有开服教程的作者直接给了下限：4 核 8G 起，CPU 要高主频高单核。这个建议和“2 核 2G 带 2~5 人纯净服”并不矛盾，差的不是人数，是服务端类型和版本——纯净小服和塞满 mod 的整合包完全是两种负载。

**基岩版。** 比 Java 版省资源，2 核 2G 能带到 10 人左右在线。

两个容易被忽略的硬件项：上行带宽只有 3Mbps 时，6~8 人同时在线就可能卡，10Mbps 以上更保险；磁盘必须是 SSD，机械盘拖区块加载，卡顿表现为“跑着跑着突然一顿”，很难从 CPU 上找原因。

## 二、为什么 MC 服要先看单核

MC 服务端主要单线程运行。世界 tick、实体 AI、方块更新、区块生成都挤在主线程上，核心再多也只有一两个在满载干活。主频和单核性能直接决定 TPS 稳不稳，1.18 之后世界高度和区块负载上来，高版本对单核的要求又抬了一截。

所以挑机器时，“几核”只影响你能同时跑几个服务端实例，“主频多高”才影响单个服卡不卡。

| CPU | 单核频率 | 大致适合 |
| --- | --- | --- |
| E5-2666 v3 | 2.9GHz | 低版本小生存、挂机服，模组服别考虑 |
| Platinum 8275CL | 3.9GHz | 多核强单核弱，低版本模组或高版本纯净插件 |
| Gold 6146 | 4.2GHz | 纯净插件服，负载中等 |
| Ryzen 9 5900X | 4.8GHz | 中高版本模组、小型群组、基岩版 |
| Ryzen 9 7950X | 5.7GHz | 高版本整合包、插件与模组混开 |
| Ryzen 9 9950X | 5.7GHz | 同上，架构更新，单核更强 |
| i9-14900K / KF | 6.0GHz | 1.20+ 大型模组整合包、几十人起步的群组服 |

一句话判断：跑 1.18 以上的模组服，往 5900X 以上挑；只跑纯净或轻插件，至强那几档够用，省下来的钱加内存更划算。

## 三、雨云游戏云的机型怎么对应

雨云有两条产品线。游戏云（RGS）自带 MCSM 可视化面板，另一条是普通云服务器，给你一台完整的 Linux 或 Windows 虚拟机。区别在于面板线把开服流程做成了网页操作，裸机线里 Java、jar、启动脚本都得自己来。

面板线里几个和 MC 直接相关的设定值得先知道：

- **NAT 共享 IP 版本**靠端口转发对外提供服务，开一个 MC 服只占一个端口，够用；要独占公网 IP 得选独立 IP 版本，价格更高。

- **150G 共享 DDoS 防御**是随产品附带的基础防护。
- **自动备份、自带 MySQL**，面板里可以直接操作。

## 四、面板服和 VPS 裸机，开服难度差多少

面板路线五步：下单选机型 → 进控制台打开 MCSM → 新建 Minecraft Java 版实例，选 Paper、Spigot、Forge、Fabric 或原版 → 设端口 → 点启动，把“IP:端口”发给朋友。卡住的地方通常在端口映射，NAT 模式下要在面板里手动转发 25565，照着做两三步的事。

VPS 路线是这样的：

1. SSH 连上服务器，装 Java 21。1.21 服务端强制要求 Java 21，教程用的阿里 Dragonwell 21.0.3.0.3+9，装完 `java -version` 要能看到 `openjdk version "21.0.3.0.3"`。
2. 下载服务端 jar，教程里用的是 paper-1.21-50。
3. 写启动命令。教程里那条是 `java -server -Xms128M -XX:MaxRAMPercentage=95.0 -Dfile.encoding=UTF-8 -Duser.country=CN -jar paper-1.21-50.jar`，`-XX:MaxRAMPercentage=95.0` 限制 JVM 用 95% 可用内存，`-Dfile.encoding=UTF-8` 防中文乱码。
4. 首次启动会停在 `You need to agree to the EULA in order to run the server`，去 `eula.txt` 把 false 改成 true。
5. 关正版验证、改端口在 `server.properties` 里，改完重启实例；同机跑多个服要给不同端口。

# -Xmx4G`，去掉注释设成实际内存（且不能超过服务器物理内存），最后把启动命令改成 `bash run.sh`。Mohist 这类模组加插件混合的服务端版本跟进更慢，教程实测时只到 1.20.2，想混开的人先确认目标版本有没有发布。

## 五、真实花费怎么算

雨云的账单价由几块拼起来：机型月付价、你选的计费周期、当期优惠券、游戏云的电量费。要算准第几个月花多少，得按下面几件事拆。

**优惠券只作用于第一期。** 新用户券通常有有效期和适用产品范围，用掉之后第二期回到原价。判断“贵不贵”时，先看没有券的月付价，再看券能省多少。

**长周期付费有折扣，但和券的叠加规则要看下单页。** 季付、半年付、年付的折扣力度不同，能不能同时用券以下单页结算为准。年付锁定的好处是避开后续调价，代价是退款窗口仍然只有 7 天，后面会讲到。

**游戏云的电量费跟着负载走。** 一个长期满载的模组整合包服，电量部分会实打实进账单；一个只有晚上有人上线的私人服，这部分反而不多。下单前确认电量怎么计、有没有上限。

**余额、积分和券不是一回事。** 积分兑换的免费机型是有的（低配至强那两档），但要看清兑换后是否还能正常退款——官方退款政策写明，领过产品消费积分的订单不支持退订。

退款条款是这里最该先读的一段，雨云官方政策写得很具体：

- 7 天无理由，在产品控制面板点“退订”自助操作，**每位用户总共 3 次机会**。
- 领取过产品消费积分、1 元试用后已续费、或超过 7 天的订单，不能退。
- 日付、流量包、游戏云电量、IP 增加、硬盘或套餐升级等非月付场景不支持退订。
- 限流套餐日流量超过 100G 会自动失去 7 天无理由资格。
- 新购订单退订时，用掉的优惠券原路退回，退成券而不是现金。
- 如果雨云业务变更导致产品不可用，按“购买价 ÷ 天数 × 剩余天数”退款到账户，需在产品不可用后 7 天内申请。

## 六、什么情况别选雨云

三种情况我建议直接跳过：

**玩家在海外。** 雨云的海外机房相对少，主力在国内。给国际玩家开服，延迟会是第一个被抱怨的问题。跨境线路里香港节点到内地大约 40~80ms，欧美节点明显更差；如果你的玩家分散在海外，得按他们的位置选机房，而不是按价格。

**要 99.99% 以上 SLA 的商业服。** 雨云主打性价比，定位不是高端商用。靠这个服收费、掉线就有人退款的场景，去看有正式 SLA 条款的厂商。

**要内核级调优的极客服主。** 想改内核参数、自己编译核心、做深度性能调优的，面板服和这类性价比机型都不是为你准备的，你需要的是完全可控的裸机。

反过来，几个朋友联机的私人小服、想跑高版本模组又对延迟敏感的国内服主、零基础第一次开服的人，是这类产品的目标用户。

只想两三个人随便玩玩、预算压到极低，除了国内性价比机型，也可以看香港的低价小机——免备案、部署快，2 核 2G 带两三人纯净服够用，代价是带宽通常小、上限低。这条路我不做具体推荐，自己按上面的配置分档去对就行。

## 七、下单前确认三件事

**NAT 还是独立 IP。** 纯 MC 服用 NAT 共享 IP 加端口转发就够，一个服占一个端口。要跑多个服务端、或者需要固定公网 IP 给别的用途，才考虑独立 IP 版本。这一项选错，后面改起来要重新部署。

**内存按人数和服务端类型对。** 纯净 2~5 人 2G 够，插件服 2G 勉强，模组服直接 4G 起，高版本大型整合包按 8G 准备。宁可内存多一档，也别在 CPU 上省——内存不够表现为崩服，主频不够表现为持续卡顿，后者更难忍。

**退款窗口和次数。** 7 天、总共 3 次、领积分后失效。第一次买建议先月付试一个月，跑顺了再换年付锁价，这样万一机型不合适，损失可控。

## 八、几个常见问题

**2 核 2G 到底够不够？**
看服务端类型。Java 版纯净原版 2~5 人在线可以，Paper 加轻插件勉强，Forge/Fabric 模组服不够，基岩版能带 10 人左右。

**面板服和 VPS 选哪个？**
没碰过 Linux、只想尽快开服，选面板。要装自定义插件、改配置文件、跑多个实例、做深度调优，选 VPS。面板能做的事 VPS 都能做，代价是你得会。

**基岩版和 Java 版配置差多少？**
基岩版省资源，2 核 2G 能到 10 人左右；同样配置换 Java 版，纯净服只能带 2~5 人。

**首月优惠之后续费多少？**
取决于你选的机型和计费周期，券只覆盖第一期。下单页会显示每期的应付金额，按那个数字乘周期数算总账，别按首期价推算。

**想同时装模组和插件怎么办？**
Mohist 这类混合服务端可以，但版本跟进慢，教程实测时只到 1.20.2。版本对不上就得二选一：要么降版本用混合端，要么分开开两个服。
